# 情侣卡牌

入口在大橘日记下方。设计给异地情侣线下见面用：抽卡攒券，见面时打出来兑现。
应用只记录双方约定的效果，不代替现实中的沟通与同意。

**完整卡面（21 种 × 4 稀有度共 84 张）以 `server/src/cardGame/catalog.ts` 为准**，
文档不再重复维护表格。大类：

- **亲密卡**：时间型（普通 5 / 稀有 10 / 史诗 20 / 传说 30 分钟）。
- **红包卡**：即时型，按稀有度递增金额，传说是请吃一顿饭。
- **情绪卡**：和好、道歉、安心、冷却期、情书，按稀有度加深完成度。
- **选择权卡**：餐食/娱乐/地点/行程/酒店，分歧时持卡人方案获得决定权。
- **辅助卡**：加时、延期、复制对方一张卡、乾坤大挪移（把对自己生效的效果
  转回对方）。辅助卡需要选择目标效果或目标卡。

## 运行规则

- 每天一个六张牌的翻牌阵（3+3 对称，Asia/Shanghai 自然日换新），点一张翻一张，
  每张独立约 1/6 翻中，无保底。已翻结果服务端记录，跨设备还原牌阵。
- 命中权重：普通 60% / 稀有 25% / 史诗 12% / 传说 3%；客户端绿/蓝/紫/金显示，
  金卡有独立闪光与揭示动画。
- 卡入个人卡库可跨天保存；使用扣一张库存，无冷却。
- 即时卡立即生效；时间卡从服务端确认使用时开始倒计时，多个效果可并行。
- 加时/延期只能作用在**自己打出的**效果上；乾坤只能转移**对自己生效的**效果。
- 客户端有**图鉴**（卡牌页右上角）：84 张全集、已收集/未收集、可看对方收集进度。
- 出牌记录对双方展示卡名、**卡面内容**、关系与时间。
- 服务端用事务 + 账号幂等键保证重复请求不重复扣卡。
- 当前版本不发通知、不写聊天消息、不接 Sync/Socket；卡牌页前台每 8 秒轮询。
