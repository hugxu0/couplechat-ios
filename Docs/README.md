# 文档入口

按任务选择，不用从头读完。

| 文档 | 什么时候看 |
|---|---|
| [PROJECT.md](PROJECT.md) | 当前版本、功能、已知问题 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | 开始改代码或找入口 |
| [SERVER.md](SERVER.md) | 检查或发布服务器 |
| [IOS.md](IOS.md) | 构建、签名、安装 IPA |
| [API.md](API.md) | 改 REST、Socket 或 Sync 字段 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 改消息可靠性、数据库或同步 |
| [AI.md](AI.md) | 改大橘、Memory、MCP 或模型调用 |
| [CARD_GAME.md](CARD_GAME.md) | 改卡牌玩法 |

原则：状态写进 PROJECT.md、契约变了才更新 API.md、秘密不进仓库、
过程留给 Git 历史——不维护审计式流水账。
